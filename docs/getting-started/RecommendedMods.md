# Recommended Mods

Mods are optional on EarthPol, but some can improve your experience.

## Simple Voice Chat

We recommend **Simple Voice Chat** for proximity voice communication.

- Works in the **Lobby** and **Main Server**
- Fully **opt-in** (you can disable it at any time)
- Gameplay is unchanged if you do not install it

You can find the mod here: [Simple Voice Chat on Modrinth](https://modrinth.com/mod/simple-voice-chat)

### Quick Setup

1. Install your preferred mod loader for your Minecraft version.
2. Install **Simple Voice Chat** for the same game version and loader.
3. Join `play.earthpol.com`.
4. Configure your voice settings in-game (default keybind is `V`).
