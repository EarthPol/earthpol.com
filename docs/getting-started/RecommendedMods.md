# Recommended Mods

Mods are optional on EarthPol, but some can improve your experience.

## Simple Voice Chat

We recommend **Simple Voice Chat** for proximity voice communication.

- Works in the **Lobby** and **Main Server**
- Fully **opt-in** (you can disable it at any time)
- Gameplay is unchanged if you do not install it

You can find the mod here: [Simple Voice Chat on Modrinth](https://modrinth.com/mod/simple-voice-chat)

### Quick Setup

1. Install your preferred mod loader for your Minecraft version.
2. Install **Simple Voice Chat** for the same game version and loader.
3. Join `play.earthpol.com`.
4. Configure your voice settings in-game (default keybind is `V`).

### Group Chats (How They Work)

Simple Voice Chat groups are private voice channels. They let you talk with specific players even when you are far apart, instead of only using proximity voice.

- Players outside your group cannot hear your group chat.
- You can still leave and return to normal proximity chat at any time.

### Create a Group (Menu Method)

1. Press `V` to open the voice chat menu.
2. Click the **Group** button to open the group screen.
3. Choose **Create Group** (wording may vary slightly by version).
4. Enter a group name.
5. Optional: set a group password before creating it.
6. Confirm to create the group.

If your version does not have a default Group keybind, open Minecraft controls and set a key for the voice chat group menu.

### Invite Someone to Your Group

You can invite players in either of these ways:

- Run: `/voicechat invite <playername>`
- Use the Social Interactions screen and invite them from there

### Join, Leave, and Manage Groups

- Open the group screen from the voice chat menu to join available groups.
- If a group is password-protected, enter the password when joining.
- Use group menu options to leave your current group when you want to return to normal proximity voice.
