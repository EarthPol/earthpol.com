Brewery is a plugin that allows players to brew custom alcoholic and non-alcoholic drinks. It introduces a complex brewing process involving fermentation, distillation, and aging in barrels.

Players can discover various recipes, ranging from simple beers and wines to strong spirits. Drinking these brews can lead to drunkenness, which includes effects like slurred speech in chat, stumbling, and visual distortions.

For more technical details or to view the source, you can check out the [BreweryX GitHub repository](https://github.com/BreweryTeam/BreweryX).

---

## Brewery Guide

To brew drinks:
- Place a cauldron on a heat source (Lava, magma, fire, any fire or campfire) and fill it with water
- Add the ingredients defined in the recipes section (Messing this up can ruin your drink)
- Leave it for the time specified (You can check this by clicking the cauldron with a clock)
- When it has boiled for long enough, collect it with a bottle.
- If your recipe requires aging, place it in a barrel of the correct wood type. (Refer to the image below)
- If your recipe requires distillation, place it in a brewery stand with glowstone.

export const RecipeGrid = ({ recipes, initiallyVisible = recipes.length }) => {
  const [visibleCount, setVisibleCount] = useState(initiallyVisible);

  const showMore = () => {
    setVisibleCount(recipes.length);
  };

  return (
    <div>
      <div className="kpi-grid">
        {recipes.slice(0, visibleCount).map((recipe, index) => (
          <div className="kpi-card" key={index}>
            <div className="kpi-value">{recipe.name}</div>
            <div className="kpi-label">{recipe.quality}</div>
            <div className="kpi-label"><strong>Ingredients:</strong> {recipe.ingredients}</div>
            <div className="kpi-label"><strong>Cook:</strong> {recipe.cook}</div>
            <div className="kpi-label"><strong>Age:</strong> {recipe.age}</div>
            <div className={recipe.alcohol > 25 ? "kpi-percent kpi-percent-red" : "kpi-percent"}>
              Difficulty {recipe.difficulty} · Alcohol {recipe.alcohol}%
            </div>
          </div>
        ))}
      </div>
      {visibleCount < recipes.length && (
        <button onClick={showMore} className="show-more-button">
          Show More
        </button>
      )}
    </div>
  );
};

## Garden Plugin

The Garden plugin is a companion to Brewery, adding a variety of new crops and ingredients that can be used in brewing recipes. Many of the drinks listed above, such as those requiring berries, grapes, or various fruits, depend on the Garden plugin.

This plugin expands the agricultural side of the server, allowing players to cultivate a wider range of plants and create more complex and unique brews.

For more information on the crops and mechanics of the Garden plugin, you can visit its official page on [Hangar](httpss://hangar.papermc.io/BreweryTeam/Garden).
