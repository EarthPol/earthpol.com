# Bounty System

## Headhunters - EarthPol's Bounty Plugin
Headhunters is EarthPol's exclusive player bounty system.

- `/bounty set PlayerName amount` - Set bounty on a player
- `/bounty list` - See all active bounties.
- `/bounty remove PlayerName` - Remove the active bounty that you have set on a player

- The bounty is claimed in full by whoever kills the player.
- Bounties cannot be claimed when the kill is made inside of a Towny arena plot.
