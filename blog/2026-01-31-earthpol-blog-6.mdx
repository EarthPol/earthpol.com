import React, { useEffect, useState } from 'react';

export function DaysOnline() {
  const [days, setDays] = useState(0);

  useEffect(() => {
    const startDate = new Date('2025-06-07'); // Version start date
    const today = new Date();
    const diffTime = today.getTime() - startDate.getTime(); // Difference in milliseconds
    const diffDays = Math.floor(diffTime / (1000 * 60 * 60 * 24)); // Convert to days
    setDays(diffDays);
  }, []);

  return <strong>{days}</strong>;
}

## Hello EarthPol!

Welcome to our first blog post of 2026. January was an exceptional month that built upon the momentum we saw in December 2025, which you can read about [here.](/blog/earthpol-blog-5) This month's post looks at the progress, milestones, and numbers that made the start of the year such an important moment for EarthPol.

## Landmark Version

I’m pleased to announce that this version of EarthPol is now officially the longest-running in the server’s five-year history. Before Astra, the record was held by Nebula, which lasted 235 days. Astra has currently been online and active for <DaysOnline /> days!

Since June 2025, our server has grown and thrived, and we’re excited to soon surpass a full year of uptime. This effort would not have been possible without our dedicated staff and amazing community!

## Development

With the server growing at this pace, we shifted much of our focus in January toward strengthening EarthPol’s technical foundations. Many of the changes below are not immediately visible in gameplay, but they greatly improve the accuracy, stability, and long-term reliability of core systems.

Several of these developments were originally planned for a future major update, but we chose to release them early to support the server’s current growth.

### SiegeWar Improvements
- SiegeWar Backend Update: SiegeWar now supports tracking Banner Control and Penalty Points for addon plugins and includes unique siege identifiers to distinguish repeated sieges on the same town.
- SiegeStats: Siege statistics have been expanded to track all point events, including kills, deaths, banner captures, and penalty points, both per session and per siege. Due to structural changes in SiegeWar, existing tables were reset, which should be the last time this is necessary. The /siegestats command provides detailed statistics and leaderboards for sieges, allowing players to track performance both globally and within individual sieges.
    - `/siegestats current`: View your stats in the current active siege.
    - `/siegestats profile [player]`:  View global totals for a player across all sieges.
    - `/siegestats top [stat] [page]`:  View the global leaderboard for a specific stat.
    - `/siegestats [siege] top [stat] [page]`:  View the leaderboard for a specific siege.
    - `/siegestats [siege] player [player]`:  View a player’s stats within a specific siege.
    - `/siegestats [siege] kills [player]`:  View who a player killed during a specific siege.

![Lobby](/img/SiegeCover.avif)

- New SiegeWar Stats Page: A new ``/sieges`` endpoint is available on the [EarthPol Observatory website](https://earthpol.org/sieges), check it out!
- Death Message Cooldown: A 30-second cooldown has now been added to death messages when a custom lore weapon with an incrementing kill counter is involved. The kill counter will still increment but this is intended to limit chat spam.
- Live Siege Tracker: We’ve launched a [live Siege Tracker](https://earthpol.org/sieges) that gives real-time visibility into active sieges, ongoing sessions, and results.

These SiegeWar and SiegeStats improvements mark the first time in EarthPol’s history that sieges can be tracked with complete historical accuracy. Every battle session, kill, and capture is now recorded in a way that allows for reliable leaderboards, analytics, and external tools. This lays the groundwork for future features that were previously impossible to build.

### Updated Lobby
- KitPvP: KitPvP is now available in the lobby, featuring a [live leaderboard](https://earthpol.org/kitpvp) to track your progress.
- Domination/Revenge Kills: Similar to mechanics seen in other games, if a player is killed three times by the same player without any deaths, they will be marked as "Dominated." If the dominated player kills the person who is dominating them, they will get a "Revenge" kill.

![Lobby](/img/earthpol-lobby.avif)

#### What's next for the lobby?
- EarthPol Museum: Our intention is to bring back a bigger and better EarthPol Museum that does not impact performance.
- Parkour Timer: We are currently working on our own custom Parkour Timer plugin to be added to the lobby.
- Tutorial Section: We are interested in expanding upon our guides and having a dedicated tutorial area within the lobby for new players.

### Security Upgrades
- Vulcan AntiCheat: With Folia support now available, Vulcan has returned to EarthPol, making us one of the first Folia-based servers to implement it. Having used Vulcan prior to Folia, we’re excited to bring it back as we expect it will catch cheaters more efficiently and create a fairer experience for everyone.
- Custom VPNShield: Our custom-built anti-VPN system improves alt account detection and helps us maintain the high standards of security and fairness we uphold.
- Wiki Account Verification: An email is now required when creating a new wiki account. This improvement helps protect the EarthPol Wiki against griefing while ensuring account security.

### API Changes
- /shops API: No longer returns empty shops, shops priced over 100,000G, or shops outside the primary world.
- /sieges API: Now correctly returns battleSession timers in long format, making it easier to build automated notifications.
- SiegeWar & SiegeStats:
  - Fully rebuilt siege system
  - Tracks each siege individually
  - Records every battle session within a siege
  - Tracks all kills during each session
  - Tracks every banner capture point earned

Leaderboards are now accurate, historical stats work properly, and points are tracked correctly across the entire war system.

### EarthPol Observatory Updates
- ``/shops``: Now automatically recommends the most viewed item stacks for easier access.
- ``/shops``: Continues to provide auto-suggestions even if a space is used instead of _ in item names.
- ``/nations``: Deleted nations are no longer displayed, but data is retained for an upcoming reports feature.
- ``/towns``: Deleted towns are no longer displayed, but data is retained for a future feature set.

### 1.21.11 Update
On January 19, EarthPol officially updated to 1.21.11, which includes many amazing features such as shelves, lances, and copper golems.

### Additional Changes
- Item Pickup Priority: Our new custom solution temporarily restricts newly dropped items, including weapons, armor, tools, and rare materials, to their original owner for 5 seconds to prevent theft during mining, drops, or container breaks.
- In-Game Calendar: We’ve added /calendar, an in-game system that lets players view upcoming events, community activities, and server-wide moments directly within Minecraft and reduce reliance on Discord.
- Mapcolor Rework: For Premium users, ``/mapcolor`` now supports two options, *border* and *area*, allowing you to set the outline and fill colors of towns within your nation using the format ``/mapcolor [option] [color]``.
- New Vote Site - Our server has now been added to [Minecraft Server List (MCSL)](https://minecraft-server-list.com/server/517249/).
- Added more emojis like ``:joy:``, ``:sob:``, ``:pensive:``, ``:nerd:``, ``:cookie:``, ``:cake:``, ``:party:``, ``:fire:``, ``:robot:``, ``:gem:``, ``:balloon:`` and ``:eyes:`` to translate in-game to their unicode equivalent.

Many of these smaller changes are part of a broader goal to make EarthPol feel more alive from inside the game itself. Features like the in-game calendar, map color improvements, and item pickup priority all contribute to a smoother and more immersive experience for both new and veteran players.

### Bug Fixes
- Fixed an issue that led to players being kicked when using Easyplace.
- Fixed an anvil bug that allowed for Lunge V.
- Cleaned up the [Custom Recipes](https://earthpol.com/docs/economy-trade/custom-recipes/) page to be updated and user-friendly.

- New Major Update: Currently, we are on track to release our next major update in mid-February.
